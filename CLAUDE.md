# Tortoise Labs portfolio site

Static single-page site deployed to GitHub Pages at tortoiselabs.io (repo: clintbeharry/tortoiselabs, branch `main`). See `index.html` — plain semantic HTML with all styling inline; do not refactor styles into CSS classes, a stylesheet, or a framework.

## Copy rules

- No em dashes.
- No semicolons.
- Prefer comma splices over semicolons when joining two related independent clauses (e.g. "Connection isn't a feature you add to a crowd, it's a sequence you design.") — this is the site's established voice, not a grammar error to fix.
- Don't rewrite, "tighten," fix grammar, or change punctuation beyond what's explicitly requested.
- Ampersands stay escaped as `&amp;` where they already are.
